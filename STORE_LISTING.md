## Detailed description

> IsItTrue helps you spot misinformation before you share it.
> Select any text on a page, or right-click an image (a screenshot, meme,
> or forwarded photo), and IsItTrue breaks it down claim-by-claim:
> what's supported, what's false, and what can't be verified — with a
> plain-language reason for each.
>
> No account, no sign-up. Just right-click and check.
>
> - Works on any website, not just one messaging app
> - Checks text and images, including text printed inside an image
> - Clear ✅/❌/❓ verdicts per claim, not just a single yes/no
>
> Verdicts are generated by AI and can be wrong — always use your own
> judgment for anything important. See our privacy policy for what
> happens to what you submit.

## Permission justifications (the Store asks for these explicitly)

- **`contextMenus`**: required to add the "Check this text/image with
  IsItTrue" right-click menu entries — the extension's only user
  interaction surface.
- **`storage`**: used with `chrome.storage.session` to hand off the
  selected text or image reference from the background service worker to
  the results page it opens. Cleared immediately after being read; nothing
  persists between checks.
- **`host_permissions: <all_urls>`**: needed for two things — (1)
  fetching the actual image bytes when you right-click an image, from
  whatever site you're on (unknown in advance, so it can't be scoped to a
  fixed list), and (2) calling our backend API to run the check. Be ready
  for a reviewer to push back on this being broader than `activeTab` would
  allow — if so, the fallback is testing whether `activeTab` +
  `optional_host_permissions` (requested only when an image check is
  actually invoked) covers the image-fetch case, narrowing the permanent
  grant. Not yet tested; do this if the review flags it.
